# 文档管理工具前端模块实现方案

## 概述

> 技术栈：Vue3.5.40 + Vite + ElementPlus + Pinia + Vue Router + Axios + markdown-it + highlight.js

### 初始准备

```bash
npm create vue@latest doc-manager-ui
npm install element-plus axios pinia
npm install markdown-it highlight.js
```

## 核心功能和页面设计

### 主布局MainLayout

* 左侧导航菜单：文档管理、分类管理、标签管理、全局搜索。
* 顶部：应用名称、可能的后端连接状态。
* 内容区：<router-view> 显示各个页面。

### 文档列表页

#### 功能

* 分页表格展示文档，列：标题、文件类型、片段数量、创建时间、更新时间、操作。
* 顶部工具栏：搜索输入框（按标题关键词）、导入按钮。
* 操作：查看片段（跳转 SectionList）、删除文档

#### 接口

* GET /api/documents?page=&size=&keyword=
* DELETE /api/documents/{id}

### 片段列表页

#### 功能

* 显示某个文档下的所有片段，分页/过滤。
* 过滤条件：分类、标签、关键词。
* 片段列表项：标题、摘要、分类、标签、更新时间、操作（编辑、删除）。
* 点击片段可查看详情（弹窗或抽屉显示 Markdown 渲染后的完整内容）。

#### 接口

* GET /api/sections?documentId=&page=&size=&categoryId=&tagId=&keyword=
* PUT /api/sections/{id} 更新片段
* DELETE /api/sections/{id} 删除片段
* POST /api/sections/{id}/tags 添加标签
* DELETE /api/sections/{id}/tags/{tagId} 移除标签

### 导入文档对话框

#### 功能

* 选择文件上传（.md/.txt）
* 调用 POST /api/import 获取预览结果，展示片段列表及分类建议
* 每个片段可修改分类、添加标签
* 确认导入：调用 POST /api/import/confirm 保存
* 导入成功后刷新文档列表

#### 接口

* POST /api/import（multipart/form-data）
* POST /api/import/confirm

### 搜索页

#### 功能

* 全局搜索输入框
* 调用 GET /api/search?keyword=&page=&size=
* 结果列表：片段标题、内容摘要、所属文档、分类、相关度标识
* 点击结果可跳转到片段详情（或对应文档的片段列表）

### 分类管理页

#### 功能

* 树形表格展示分类层级
* 新增、编辑、删除分类
* 编辑分类的规则关键词（ruleKeywords）
* 删除时需确认（后端会校验子分类）

#### 接口

* GET /api/categories/tre
* POST /api/categories
* PUT /api/categories/{id}
* DELETE /api/categories/{id}

### 标签管理页

#### 功能

* 标签列表展示
* 新增标签、删除标签

#### 接口

* GET /api/tags
* POST /api/tags
* DELETE /api/tags/{id}

### 状态管理Pinia

#### 分类状态

* 保存分类树和扁平列表，供各组件使用。
* 提供获取分类树、刷新等动作。

#### 标签状态

* 保存分类树和扁平列表，供各组件使用。
* 提供获取分类树、刷新等动作。

#### 文档/片段状态（可选）

由于文档和片段数据通常按需加载，可以不必放在全局状态中，而是由各自页面组件本地管理。但为了减少重复请求，可将分类和标签作为全局共享。

### 关键交互流程

#### 导入文档流程

1. 用户点击“导入文档”按钮，弹出对话框。
2. 选择文件后，调用 POST /api/import，展示预览列表。
3. 每个片段显示：标题、内容摘录、分类建议下拉框（自动选中最高置信度分类）、标签选择器。
4. 用户可修改分类、添加标签。
5. 点击“确认导入”，组装 ImportConfirmDTO 提交 POST /api/import/confirm。
6. 成功后关闭对话框，刷新文档列表。

#### 查看片段详情

* 在片段列表中点击“查看”，打开抽屉或弹窗。
* 通过 originalContent 字段使用 Markdown 渲染组件展示格式化的内容。
* 如果片段是纯文本，则直接显示。

#### 编辑片段

* 点击“编辑”，弹窗内使用 textarea 显示 Markdown 源码，用户修改后保存。
* 调用 PUT /api/sections/{id}，传递新的 originalContent 和可选 title。

### 附加组件设计

#### MarkdownRenderer.vue

* 使用 markdown-it 解析 Markdown，并配合 highlight.js 高亮代码。
* 接收 content 属性，输出 HTML 并设置样式。

#### CategorySelect.vue

* 基于 el-tree-select 或 el-cascader，使用全局分类树数据。
* 支持清空，绑定 categoryId。
