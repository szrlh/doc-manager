# 文档管理工具后端实现方案

## 概述

SpringBoot + Mybatis-plus + SQLite构建后端服务，提供文档导入、片段化管理、只能分类、标签、搜索等功能。核心设计思路是将导入的md/txt文档拆分为多个独立片段Section，每个片段可以独立分类、打标签、搜索和编辑。数据存储使用SQLite嵌入式数据库，通过Flyway管理表结构，Mybatis-plus提供数据访问层。

## 模块实现方案

### 文档导入模块

> 职责：接收上传文件，解析文件内容，按规则拆分为片段，调用智能分类器为每个片段给出分类建议，返回预览结果。用户确认后，持久化文档和片段数据

#### 关键类与接口

* ImportController（/api/import）
* ImportService及其实现类ImportServiceImpl
* DTO：ImportResultDTO、ImportSectionDTO、ImportConfirmDTO、ImportSectionConfirmDTO、CategorySuggestionDTO
* 工具类：MarkdownParser（拆分、格式化、解析md文档）

#### 实现思路

1. ImportController.importFile() 接收 MultipartFile，调用 ImportService.importDocument(file)
2. importDocument()方法
    * 读取文件内容，根据扩展名（.md/.txt）选择解析策略。
    * 对于 Markdown 文件：按标题行（#~######）拆分为片段，每个片段保留标题（去除#）和正文（保留原始 Markdown 到 originalContent，同时生成纯文本到 content）
    * 对于 TXT 文件：按连续空三行拆分，若无明显分隔则整个文件作为一个片段。originalContent 与 content 相同。
    * 为每个片段调用 ClassifierService.classify(text) 获取分类建议（分类ID和置信度）。
    * 组装 ImportResultDTO 返回给前端预览
3. 前端展示预览，用户可修改每个片段的分类、添加标签，然后提交确认
4. ImportController.confirmImport() 接收 ImportConfirmDTO，调用 ImportService.confirmImport(confirmDTO)
5. confirmImport() 方法
    * 创建 Document 记录（标题取用户确认的标题或默认文件名）
    * 批量插入 DocumentSection 记录，使用用户确认的分类ID
    * 为每个片段批量插入标签关联（SectionTag）
    * 将每个片段的内容和最终分类ID写入 category_training 表，用于后续分类器训练
    * 返回新文档ID

### 文档管理模块

> 职责：提供文档元数据的查询、删除等操作。文档不直接存储内容，只保存标题、文件类型等

#### 关键类与接口

* DocumentController（/api/documents）
* DocumentService 及实现 DocumentServiceImpl
* Mapper：DocumentMapper
* DTO：DocumentDTO

#### 实现思路

* 文档列表分页查询：DocumentServiceImpl.listDocuments(page, size, keyword)
  * 使用 DocumentMapper.selectDocumentPageWithSectionCount() 自定义 SQL，LEFT JOIN 片段表统计每个文档的片段数量
  * 支持按标题模糊匹配
  * 返回 IPage<DocumentDTO>
* 删除文档：DocumentServiceImpl.deleteDocumentWithSections(documentId)
  * 先删除文档下的所有片段（DocumentSectionMapper.delete(...)），再删除文档记录
  * 利用数据库外键 ON DELETE CASCADE 自动删除片段标签关联，但建议显式删除以确保逻辑清晰

### 片段管理模块

> 职责：管理文档片段，提供分页查询、更新、删除、标签管理等功能

#### 关键类与接口

* SectionController（/api/sections）
* SectionService 及实现 SectionServiceImpl
* Mapper：DocumentSectionMapper、SectionTagMapper
* DTO：SectionDTO

#### 实现思路

* 片段分页查询：SectionServiceImpl.listSections(...)
  * 使用 DocumentSectionMapper.selectSectionPageWithDetails() 自定义 SQL，关联文档表、分类表，并通过子查询聚合标签名称列表
  * 支持按文档ID、分类ID、标签ID、关键词过滤
  * 返回 IPage<SectionDTO>，其中 tags 字段为标签名称列表（由 GROUP_CONCAT 结果拆分而来）
* 更新片段：SectionServiceImpl.updateSectionWithOriginalContent(sectionId, newOriginalContent, newTitle, categoryId, tagIds)
  * 获取原片段，使用 MarkdownParser 从新原始内容生成纯文本
  * 更新 title、originalContent、content，并设置 updateTime
* 删除片段：SectionServiceImpl.deleteSection(sectionId)
  * 删除片段记录，利用外键级联删除标签关联
* 添加标签：SectionServiceImpl.addTags(sectionId, tagIds)
  * 校验片段存在，批量插入 SectionTag 记录，避免重复插入（可先查询已存在关联）
* 移除标签：SectionServiceImpl.removeTag(sectionId, tagId)
  * 删除对应的 SectionTag 记录

### 分类管理模块

> 职责：管理分类信息，支持树形结构，提供增删改查及树形数据获取

#### 关键类与接口

* CategoryController（/api/categories）
* CategoryService 及实现 CategoryServiceImpl
* Mapper：CategoryMapper
* DTO：CategoryTreeVO

#### 实现思路

* 获取分类树：CategoryServiceImpl.getCategoryTree()
  * 查询所有分类，按 parentId 构建树形结构（递归或循环）
  * 转换为 CategoryTreeVO 列表
* 保存分类：CategoryServiceImpl.saveCategory(category)
  * 校验名称唯一性、父分类是否存在
  * 设置 createTime/updateTime，执行插入或更新
* 删除分类：CategoryServiceImpl.deleteCategory(categoryId)
  * 若存在子分类，则禁止删除或级联处理（建议禁止删除，并提示用户先处理子分类）
  * 将关联片段的 category_id 置空（数据库外键 ON DELETE SET NULL 自动处理）
  * 删除分类记录

### 标签管理模块

> 职责：提供标签的创建、查询、删除

#### 关键类与接口

* TagController（/api/tags）
* TagService 及实现 TagServiceImpl
* Mapper：TagMapper

##### 实现思路

* 查询所有标签：直接调用 TagMapper.selectList(null)
* 创建标签：TagServiceImpl.createTag(name)
  * 检查标签名是否已存在（唯一约束），若存在则抛出异常或返回已有标签 
  * 插入新标签
* 删除标签：TagServiceImpl.deleteTag(tagId)
  * 删除标签记录，利用外键级联删除片段-标签关联

### 搜索模块

> 职责：根据关键词搜索片段，标题匹配优先于正文匹配。

#### 关键类与接口

* SearchController（/api/search）
* SearchService 及实现 SearchServiceImpl
* Mapper：DocumentSectionMapper（或专用自定义查询）

#### 实现思路

* SearchServiceImpl.searchSections(keyword, page, size)
  * 使用 MyBatis-Plus 条件构造器或自定义 SQL，查询条件为 title LIKE '%keyword%' OR content LIKE '%keyword%'
  * 使用 CASE 表达式计算相关度：标题匹配设为2，正文匹配设为1
  * 按相关度降序、更新时间降序排序
  * 返回 IPage<SearchResultDTO>，其中 contentSnippet 截取匹配关键词附近的内容片段
  * 关键词需转义 % 和 _，防止 LIKE 通配符干扰

### 智能分类模块

> 职责：根据文本内容预测分类，结合规则匹配和朴素贝叶斯模型

#### 关键类与接口

* ClassifierService 及实现 ClassifierServiceImpl
* 依赖：CategoryMapper、CategoryTrainingMapper
* 可选工具：Smile 库（用于朴素贝叶斯）或自实现

#### 实现思路

* 规则匹配（冷启动）：
  * 从所有分类的 rule_keywords 中解析关键词列表
  * 对输入文本进行包含匹配，统计命中次数，计算得分
  * 得分归一化为置信度
* 机器学习分类器（训练数据充足时）：
  * 使用 category_training 表中的历史数据训练朴素贝叶斯模型
  * 可用 Smile 库的 NaiveBayes 或自实现多项式贝叶斯
  * 模型预测类别概率
* 融合：
  * 当训练样本数量达到阈值（如20条），将规则得分与模型概率加权融合（如规则0.4，模型0.6）。
  * 返回分类ID和综合置信度的映射，按置信度降序。
* 模型持久化：
  * 训练后的模型可序列化保存到文件，应用启动时加载（可选，当前数据量小可每次重新训练）。

#### 实现位置

* Service：com.szr.docmanagerweb.service.ClassifierService、com.example.docmanager.service.impl.ClassifierServiceImpl
* 可能添加工具类：com.szr.docmanagerweb.classifier.RuleBasedClassifier、BayesClassifier 等

## 关键细节实现

### Markdown 解析与纯文本生成

* 拆分规则：
  * Markdown：按行检测标题（1~6级），每个标题开始一个新片段。
  * TXT：按连续三个换行符拆分（\n\s*\n\s*\n），若无分隔则整个文件作为一个片段。
* 纯文本生成：
  * 去除 Markdown 标记：标题符号#、强调符号*/_、代码围栏、列表标记、链接等。
  * 可使用正则表达式或现成库（如 flexmark、commonmark），但为避免额外依赖，可自行实现简单的替换。
* 标题提取：片段内第一个标题行（去除#和空格）作为 title。

### 标签聚合展示

* 在片段列表查询中，使用 SQLite 的 GROUP_CONCAT(t.name) 将标签名称聚合为逗号分隔的字符串。
* 在 Service 层将字符串拆分为 List<String> 赋值给 SectionDTO.tags。

### 分页处理

* 统一使用 MyBatis-Plus 的 IPage 和 Page 类。
* 在自定义 SQL 方法中传入 Page 参数，MyBatis-Plus 拦截器自动生成分页语句（LIMIT/OFFSET）。

### 时间字段处理

* 实体类中时间字段为 String，与数据库 TEXT 一致。
* 默认值由数据库生成（datetime('now','localtime')），插入时无需显式设置；更新时手动设置 updateTime 为当前时间字符串。
* 在 Service 层可使用 LocalDateTime.now().format(DateTimeFormatter.ofPattern("yyyy-MM-dd HH:mm:ss")) 生成。

## 数据流与交互

### 导入流程

1. 用户上传文件 → ImportController.importFile()
2. 后端解析文件、拆分片段、调用分类器 → 返回 List<ImportResultDTO> 预览
3. 前端展示预览，用户调整分类、标签 → 提交 ImportConfirmDTO
4. 后端 ImportController.confirmImport() → 创建文档、片段、标签关联、训练数据 → 返回文档ID

### 搜索流程

1. 用户输入关键词 → SearchController.search()
2. 后端构建查询，按相关度排序 → 返回 IPage<SearchResultDTO>
3. 前端展示结果，可点击进入片段详情
